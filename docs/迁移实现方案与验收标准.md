> 配套：`docs/薄肌系统迁移追踪台-架构方案-v3-定稿.md`（设计与决策）
> 本文是**执行规格**：把 v3 落成可派遣的工程包，含接口边界与验收标准。
> 生成日期：2026-10-15

## 1. 需求分析

### 1.1 目标
把薄肌系统（`index.html`，369,561 字节）的**全部内容**迁入减脂追踪台（`tracker.html`，176,233 字节）的**壳与设计体系**，产出一个单文件应用。

### 1.2 关键点（决定成败的三条）

| # | 关键点 | 为什么关键 |
|---|---|---|
| K1 | **内容零丢失** | 用户第一诉求。术语表与 54 个字段标签藏在 UI 模块内部，最易被误删 |
| K2 | **逻辑层零改动** | 17 个模块承载全部业务规则，改动即引入回归风险 |
| K3 | **壳与内容彻底解耦** | 源系统的 CSS（52,363 字符）与双语层必须清除干净，否则会有样式/文案残留 |

### 1.3 约束条件

| 约束 | 值 | 来源 |
|---|---|---|
| 技术栈 | 单文件 HTML/CSS/JS，零依赖、可离线 | 源项目既有硬约束 |
| 输出形态 | 一个 `.html` 文件 | 同上 |
| 存储键 | **不得改名**（`thinMuscle.trainSys.v1` / `thinMuscle.backup.v1.*`） | 键内存有用户真实数据 |
| 注入契约 | **不得改名**（`window.__TM_PROFILE__` / `__TM_TARGETS__`） | 用户本地 `profile.local.js` 依赖 |
| 源文件 | **只读**，任何情况下不得修改 | 安全红线 |
| 测试锚点 | 架构侧已改为双结构兼容；**断言不得改动** | 迁移改变 DOM 结构，锚点须同步维护 |
| 图标 | 不用 emoji 作功能图标 | 项目既有约定 |
| 硬编码色值 | 禁止（`#fff` / `#000` 除外），一律走追踪台令牌 | 项目既有约定 |

### 1.4 技术难点

| # | 难点 | 应对 |
|---|---|---|
| T1 | **术语表与字段标签藏在 UI 模块内部** | 抽取时显式分离，纳入内容层；用内容指纹验收 |
| T2 | **双语层摘除有残留风险** | 已精确测绘（见 §4.3），10 个构件 + 16 处调用点 |
| T3 | **`DERIVED` 求值早于数据加载 3,830 行** | 不改时序，改用旁路回填脚本（见 §4.5） |
| T4 | **命名冲突** | 源系统与追踪台有 20 个类名重复，但**本方案不复用源 CSS**，故冲突消失 |

## 2. 实现架构

### 2.1 总体思路：构建脚本装配，而非手工改写

理由：
- 源文件 36 万字节，手工改写不可审查、不可复现
- 逻辑层必须**逐字保留**——只有"抽取"能做到逐字，改写做不到
- 后续 13 个页面可分批交付，每次重新装配即可

```
源（只读）                        构建                          产物
─────────────────────    ─────────────────────    ──────────────────
index.html                 extract.py                out/index-tracker.html
  ├ 逻辑层 17 模块    ──→    ↓ 抽取                    （单文件交付物）
  ├ GLOSSARY 术语表   ──→   build/parts/
  └ KB 字段标签       ──→   ├ tm-logic.js    （逐字）
                            ├ shell.css      （双语层已摘）
tracker.html                ├ shell.html     （骨架）
  ├ CSS               ──→   ├ shell.js       （行为）
  ├ 骨架 HTML         ──→   ├ atoms.css      （6 个新原子）
  └ 行为 JS           ──→   └ pages.js       （13 页面渲染）
                                          ──→  assemble.py ──→ 产物
```

### 2.2 文件与接口边界

| 文件 | 职责 | 输入 | 输出 | 禁止 |
|---|---|---|---|---|
| `extract.py` | 从两个源抽取构件到 `build/parts/` | 两个源文件 | 5 个构件文件 | 不得改写源文件 |
| `assemble.py` | 装配成单文件 | `build/parts/*` | `out/index-tracker.html` | 不得内联业务逻辑 |
| `build/parts/tm-logic.js` | 薄肌逻辑层 + 术语表 + 字段标签 | — | — | **不得任何改写** |
| `build/parts/shell.css` | 追踪台样式 | — | — | 不得加页面专属选择器 |
| `build/parts/shell.html` | 侧栏 13 项 + 页面容器 + 弹窗 | — | — | 不得内联事件处理器 |
| `build/parts/shell.js` | `setPage` / `openModal` / `toast` / 主题 / 颜色自定义 / 引导 | — | — | 不得含双语层 |
| `build/parts/atoms.css` | 6 个新原子 | — | — | 不得硬编码色值 |
| `build/parts/pages.js` | 13 个 `render<Page>()` | — | — | 不得直接操作 `localStorage` |

### 2.3 模块接口（页面渲染约定）

```js
/* pages.js 契约：每个页面导出一个渲染函数，写入指定容器 */
function renderLibrary(root){   // root = 该页面的 section 元素
  root.innerHTML = `...`;        // 只负责渲染，不负责数据持久化
}
const PAGES = {
  home: renderHome, log: renderLog, diet: renderDiet, progress: renderProgress,
  plan: renderPlan, library: renderLibrary, report: renderReport,
  supps: renderSupps, herbs: renderHerbs, release: renderRelease,
  longevity: renderLongevity, skin: renderSkin, data: renderData
};
```

- **数据读写一律经 `Store` / 各逻辑模块**，页面函数不碰 `localStorage`
- **重渲染入口统一** `App.renderPage(key)`，由追踪台 `setPage()` 调用
- 事件交互统一走追踪台的数据属性委托风格

### 2.4 页面容器与导航结构

```
aside.sidebar
  ├ nav-group「训练」  今日总览 / 训练记录 / 饮食打卡 / 进度反馈 / 训练计划 / 动作库 / 每周复盘
  ├ nav-group「养护」  补剂 / 中医 / 松解
  ├ nav-group「抗老」  抗衰 / 护肤
  └ nav-group「系统」  数据备份
main.main
  ├ section.page#page-home       ← renderHome
  ├ section.page#page-log        ← renderLog
  ├ …（13 个容器）
  └ section.page#page-data       ← renderData
```

导航按钮：`data-page="library"`（复用追踪台的 `data-page` 委托，无需新事件体系）

**范围**：抽取 + 组装跑通 + 1 个完整页面作为垂直切片验证

| # | 交付物 | 说明 |

## 4. 实现规格（逐项精确到锚点）

### 4.1 逻辑层抽取（D3）

```
起点锚点：const Util = (function(){
终点锚点：const UI = (function(){     ← 不包含此行
```

必须**同时**抽取以下内容（它们定义在 UI 模块内部，是内容不是 UI）：

| 常量 | 位置 | 处置 |
|---|---|---|
| `GLOSSARY` | UI 模块内 | **抽取并原样保留**（34 条术语 / 4 组） |
| `KB_SUPP` `KB_HERB` `KB_REL` `KB_LONG` `KB_SKIN` | UI 模块内 | 抽取**字段标签部分**保留为配置常量；DOM 绑定部分（`listSel` / `attr` / `clear`）丢弃 |

> 术语表与字段标签的完整性由 §5 的内容指纹验收，**不得凭印象判断**。

### 4.2 追踪台样式抽取（D4）

- 取 `tracker.html` 的 `<style>…</style>` 全文
- 删除与页面结构耦合的 6 条规则（`#page-today>.grid>.card:nth-child(2|3)` × 浅色/深色/自定义色三套）
  - 因为 `#page-today` 不复存在；`atoms.css` 里改用显式类名 `.card.tint-peach` / `.tint-mint` 重建
- 其余样式**逐字保留**

### 4.3 双语层摘除（D6）——已精确测绘

**必删构件（10 项）：**

| 构件 | 位置 | 体量 |
|---|---|---|
| `const LANG=…` | L3 | 76 字符 |
| `const LOCALE=…` | L4 | 41 字符 |
| `const I18N={…}` | L5 | 25,021 字符 |
| `function t(value){` | L40 | 18 字符 |
| `function translateTree(root){` | L41 | 440 字符 |
| 原生弹窗包装（`nativeConfirm`/`nativePrompt`/`nativeAlert` 三处 `window.*=`） | L42 | 240 字符 |
| canvas `fillText` 补丁 | L43 | 182 字符 |
| `new MutationObserver(…)` | L45 | 208 字符 |

**清理调用点：**

- `t(...)` 调用 **13 处** → 直接去掉包装，取内层字符串
- `translateTree(...)` 调用 **3 处** → 整句删除
- `LOCALE` 引用 → 替换为字面量 `'zh-CN'`（用于 `toLocaleDateString`）

**验收**：产物中不得出现 `I18N`、`translateTree`、`MutationObserver`、`__TM` 之外的双语残留。

### 4.4 6 个新原子（D7）

全部使用追踪台令牌，**禁止硬编码色值**：

| 原子 | 用途 | 令牌依据 |
|---|---|---|
| `.kv` | 字段行（标签 + 值），替代源的 `.fld` | `--muted` / `--text` |
| `.kv-grid` | `.kv` 的两列布局 | `--grid` 间距 |
| `.tier-tag` | 分级标签（T1–T4 / 证据 A–D） | `--primary` / `--muted` / `--yellow` / `--danger` |
| `.kb-card` | 知识库卡（标题 + 分级 + 字段区 + 折叠） | `.card` 派生 |
| `.fold` | 折叠详情（追踪台对 `details` 样式化为 0 条） | `--line` / `--surface-2` |
| `.matrix` | 周矩阵（7 天 × 指标） | `.data-table` 派生 |

**色轴收敛（Q6 定案）**：无序分类标签（推/拉/腿/…）→ 中性描边；有序分级标签 → 追踪台现有令牌。

### 4.5 旁路回填脚本（D6 内）

位置：**紧接 `profile.local.js` 之后、主脚本之前**。

```js
(function(){
  if (window.__TM_PROFILE__) return;              // profile.local.js 优先，绝不覆盖
  try{
    var raw = localStorage.getItem('thinMuscle.trainSys.v1');
    if(!raw) return;
    var p = JSON.parse(raw).data.profile;
    if(p && p.weight) window.__TM_PROFILE__ = p;
  }catch(e){}
})();
```

**必须遵守**：`profile.local.js` 存在时**不得**回填。这是用户本地真实画像的最高优先级。

### 4.6 动作库页（D8，唯一完整页面）

- 数据源：`Library.list()`（49 条）、`Library.CATS`（6 分类）
- 布局：`.page-head` + `.toolbar`（搜索框 + 分类 `.segmented`）+ `.grid.grid-3` 卡片网格
- 卡片内容：名称 + 分类标签（中性描边）+ 协同肌群 + 组次 + 展开 `.fold` 显示要点/常见错误/失败模式
- 交互：搜索过滤、分类筛选、新增/编辑/删除（走追踪台 `.overlay > .modal`，删除走二步确认）
- 空态：用追踪台 `.empty`（标题 + 说明 + 可选动作），**不得出现空字符串或 `null`**

## 5. 验收标准

### 5.1 硬门禁（任一不通过即不合格）

| # | 验收项 | 判定方式 | 期望 |
|---|---|---|---|
| **A1** | **内容零丢失** | `MANIFEST_COMPARE=tools/content-baseline.json node tools/content-manifest.js migrate/out/index-tracker.html` | 阻断 0 项；指纹 `8028acf10c3684f1` 逐项复现 |
| **A2** | **逻辑层不许退化** | `verify-logic` 全绿；`verify-privacy` 分节判定 | 逻辑 68 全绿；脱敏源文件级 S1/S2/S6/S7 零失败且 S7 执行到；S3/S4/S5（依赖页面内容）允许失败，**失败越界即不合格** |
| **A3** | **源文件未被改动** | `shasum -a 256 index.html` | 仍为 `63c99e3f8bb66c82…` |
| **A4** | **无双语残留** | grep 产物 | 无 `I18N` / `translateTree` / `MutationObserver` |
| **A5** | **无源样式残留** | grep 产物 | 无源系统的 `--st-ok` / `--txt-1` / `--grad-card` 等令牌；无源 `.fld` / `.kb-card`(旧) / `.setrow` 类名定义 |
| **A6** | **无硬编码色值**（`atoms.css`） | grep | 除 `#fff` / `#000` 外无 hex |
