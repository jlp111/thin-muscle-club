# 薄肌系统 → 健身追踪台 · 迁移架构方案 v1

> 生成日期：2026-10-15
> 源系统：薄肌训练系统 ThinMuscle v3.35（`index.html`，4,863 行 / 279,101 字符 / 369,561 字节）
> 目标系统：减脂健身追踪台（`cnb-fat-loss-tracker`，Editorial Wellness 设计体系）
> 迁移性质：**系统级 UI 重构** —— 目标系统提供唯一视觉与交互基准，源系统的展示层与交互实现整体废弃，仅内容（数据模型 / 业务逻辑 / 知识与文案）迁入并重组

---

## 0. 一句话结论

源系统 279,101 字符中，**只有 18 个逻辑模块值得迁移（96,622 字符 / 34.6%）**，
其中内容资产 KbData 独占 57,681 字符（20.7%）；

**展示层 52,363 字符（18.8%）与 UI 层 125,386 字符（44.9%）整体废弃，合计 63.7%**；
剩余 4,730 字符（1.7%）为框架与启动代码。

迁移后体积预估 **150,000–190,000 字符**（HTML + 新 UI 层），页面由「13 个 tab」重组为「14 个页面 / 5 个分组的工作台」。

## 1. 完整提取成果（迁移输入清单）

### 1.1 逻辑层 —— 18 个模块，可原样迁移

**实测结论**：在 vm 沙箱中独立加载成功，全部模块只依赖 `localStorage` / `Date` / `JSON`。

对逻辑层做 DOM/BOM 全量扫描，结果：
- `querySelector` / `getElementById` / `innerHTML` / `location` / `navigator` 引用数均为 **0**
- `document.*` 与 `window.matchMedia` 仅出现在 `Theme` 模块（该模块已决定废弃）
- 其余 `window.*` 引用全部是画像注入契约：`window.__TM_PROFILE__`、`window.__TM_TARGETS__`、`window.__tm_onSaveError`

**即：剔除 `Theme` 后，其余 17 个模块可零改动搬进目标系统。**

> 附带待办：三个注入契约名带 `__TM_` 前缀（TM = ThinMuscle）。迁移后建议改为 `__WB_PROFILE__` / `__WB_TARGETS__`，并在 `profile.local.example.js` 与文档同步。**这是外部契约，改名会破坏用户已有的 `profile.local.js`，故单列为待确认项（见 D4）。**

### 3.4 色轴映射（源三轴 → 目标令牌）

源系统有严格的三轴色彩契约：status（可填充）/ cat（仅描边）/ tier（仅描边）。
目标系统调色板更克制（primary / peach / yellow / danger / muted），故：

| 源语义 | 目标令牌 | 处理 |
|---|---|---|
| status `ok` | `--primary` | 直接映射 |
| status `info` | `--primary-dark` | 直接映射 |
| status `warn` | `--yellow` / `--yellow-soft` | 直接映射 |
| status `bad` | `--danger` / `--danger-soft` | 直接映射 |
| status `mut` | `--muted` | 直接映射 |
| cat 轴 8 色（无序分类） | **中性描边标签**（`.status-tag` 默认态） | **收敛**：分类靠文字，不靠颜色。目标体系无 8 色容量，且分类上色本就与状态色抢注意力 |
| tier 轴 4 级（有序分级） | `.status-tag` 三态（primary / yellow / danger） | 4 级压到 3 档；`tier-3` 与中性合并 |
| 四个扩展标题色（anat/step/anim/ref） | `.metric-label`（muted + 大写 + 字距） | **收敛**：靠字重与字距分层，不再用色相区分 |

> 这三处「收敛」是有意的设计决策：目标系统的视觉语言用**层级与留白**表达结构，用**颜色**只表达状态。若强行保留源系统的 8 色分类轴，会与目标体系的状态色互相干扰。

| | 现状 | 目标 |

### 迁移顺序的依赖理由

- **先只读后可写**：知识库类页面（补剂/中医/松解/抗衰/护肤）只有「勾选」一种写入，逻辑最薄，可最快验证组件原子层是否成立
- **先独立后聚合**：`today` / `report` 是跨模块聚合页，依赖全部下层模块就绪
- **数据层先行**：所有页面都读 `Store`，键名与迁移函数必须先冻结，否则后续返工
