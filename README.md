# 薄肌俱乐部

> 一份只属于你的训练与身体档案。双击 `index.html` 就能用——不安装、不构建、不联网，数据也不出设备。

当前版本：**v4.5**（2026-11-05）。

---

## 项目简介

薄肌俱乐部把「训练 → 记录 → 反馈 → 调整」做成一条闭环，并把饮食、睡眠、养护和身体数据收在同一个页面里。它不做社交、不做排行，也不催你打卡，只是一份留在自己设备上的**个人记录**：

- **本地优先**：所有数据只写浏览器 `localStorage`，无账号、无 API、无同步服务；可随时导出为 JSON 备份、导入或回滚。
- **单文件自包含**：HTML / CSS / JavaScript 全在 `index.html` 里，无框架、无 CDN、无网络字体。动作演示等外链只是可选的参考链接，断网不影响任何核心功能。
- **移动端优先**：底部五项等分导航（今日 / 记录 / 饮食 / 养护 / 我的），三套深色主题（墨色 / 石灰 / 暖炭），320px 宽起无横向溢出。

## 主要功能

| 模块 | 能做什么 |
|---|---|
| **今日** | 今日安排与自适应目标（按历史表现与昨夜睡眠自动减量）、四件打卡（训练 / 饮食 / 睡眠 / 体测）、连续训练天数、吃练与进度反馈 |
| **记录** | 逐组记录重量 × 次数：**组即行**，数字后带单位（kg / 次 / min / 遍 / 圈 / 秒 / m / km / 步）、抗阻与核心下限 3 组、加一组自动继承上一组数值、未保存草稿自动恢复；可选「跟练」模式，逐组勾选后自动定位下一组并启动组间休息倒计时 |
| **饮食** | 按餐次弹窗打卡，热量与蛋白目标随画像与训练日联动，吃练匹配度提示 |
| **养护** | 五个模块页内勾选（松解 / 补剂 / 中医 / 抗衰 / 护肤），带证据等级与禁忌提醒 |
| **进度 / 周报** | 体重、体脂、柔韧、睡眠趋势；周容量与肌群分布 2×2 指标卡 |
| **我的** | 编辑资料：目标可从 7 个预设选择（薄肌 / 减脂 / 增肌 / 重组 / 力量 / 体态 / 康复）或自定义；体重体脂改动会同步写入当天体测 |
| **动作库** | 58 个动作，按肌群分类，附要点、常见错误与循证出处 |
| **系统** | 导入 / 导出 JSON、滚动留档（导入前自动快照，失败自动回退）；日期用自绘日历、时间用自绘选择面板，各平台行为一致 |

几个实现上的取舍：

- **自适应引擎**：用 Epley 公式估算 e1RM 做同动作纵向比较；昨夜睡眠不足自动减量，系数集中在模块顶部，方便一处调参。
- **安静的记录页**：全页只出现一次列名，动作卡只留「上次 / 目标」一行上下文；只有一列数值的动作（如 30min 有氧）铺满整行。
- **健壮性**：外部数据统一走 `Schema.normalize()` 补齐字段；单页渲染异常有兜底提示；本地存储写失败会明确告知，不会静默丢数据。
- **数据兼容**：`thinMuscle.*` 是历史遗留的 localStorage 键名，**保留不改**，否则老用户的数据会读不到。

## 基本使用

1. **直接打开**：双击 `index.html`，或起一个本地静态服务：

   ```bash
   python3 -m http.server 8000   # 然后访问 http://localhost:8000
   ```

   不需要 `npm install`，不需要构建。建议用 Chrome / Edge / Safari 的最新版本。

2. **改自己的资料**：进入「我的 → 编辑资料」，填写年龄、身高、体重、体脂、目标，保存后全站的目标热量、蛋白与有氧心率区间会跟着重算。体重 / 体脂改动同时写入当天体测。

3. **开始记录**：在「记录」页选日期，核对自动带出的组次，改数字、勾选完成组，最后点「保存这次训练」。改到一半退出会自动存本地草稿；训练中想跟着节拍走，可打开「跟练」，每组勾完会自动跳到下一组并开始 90s/60s 休息计时。

4. **备份数据**：在「备份」页导出 JSON 保存到本地；换设备时导入即可。建议每次大改前导出一次。

### 可选：预置画像模板

默认通过界面编辑即可。若想用文件预置，把 `profile.local.example.js` 复制为 `profile.local.js` 并填入真实值，再在 `index.html` 主脚本之前加一个 `src="profile.local.js"` 的 script 标签。`profile.local.js` 已被 `.gitignore` 排除，**不会进仓库**。

## 隐私与数据

- 仓库内只保留**中性示例画像**（30 岁 / 175cm / 67kg / 体脂 20% 等），不含真实姓名、邮箱、手机号、token、密钥或内网地址。
- 所有真实数据都在使用者自己的浏览器里；页面不发起任何数据上报。
- 开发过程记录（`.workbuddy/`）、历史版本备份、含真实数据的旧文档、截图等均被 `.gitignore` 排除。
- 若 fork 后填入个人数据，请确认 `profile.local.js` 仍处于忽略状态，不要误提交。
